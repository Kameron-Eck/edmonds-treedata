## Workstream 2: Phase 4 anchor-label experiment — ACTIVE

### Goal
More training data for the coarse year-2000 semantic model by importing labels
from the 2020 full-city inference instead of the 5 hand-reviewed sites.

### Decisions made with Kam
- **Single stage**: expand the chosen urban-forest sites, label the whole crop
  from the 2020 prob raster, tile to ~400, train year 2000. (Not whole-city, not
  two-stage pretrain.)
- **Label source**: `phase3/edmonds_canopy_prob_2020.tif` with an IGNORE band —
  `p ≥ prob_hi(0.6)` → canopy, `p ≤ prob_lo(0.4)` → background, else IGNORE.
- **Rationale**: mature urban-forest canopy is temporally stable, so 2020 canopy
  is a good prior for 2000. Risk is residential edges (trees planted/removed
  2000→2020); forest-core site selection is the mitigation. The IGNORE band only
  drops *model-uncertain* pixels, NOT temporally-changed ones.

### New CLI on `phase4_semantic_finetune.py` (live file has all of these)
- `--max-tiles N` — cap per-year tiles (canopy-first). v002 backup.
- `--stride N` — override tiling stride (smaller = more tiles). v002.
- `--site-buffer N` — pad each site footprint by N EPSG:3857 units → bigger
  crops. v003.
- `--anchor-labels` + `--prob-hi` / `--prob-lo` — import 2020 prob as labels
  (whole crop labeled; crowns/regions ignored). v004 backup = pre-anchor state.

New helper `anchor_mask_from_2020()` does a windowed/decimated read of the 110 GB
prob raster (memory-safe) and thresholds to 0/1/255.

### The run (completed ~05:46, 2026-06-23)
```
%run .../phase4_semantic_finetune.py --year 2000 --anchor-labels \
     --site-buffer 300 --max-tiles 400 --skip-inference
```
- Tiling: 607 natural tiles → capped to 400 (all canopy). Site buffer worked —
  small sites that gave 1 tile now give 49–165.
- Train: fine-tuned from `sem_best_2020.pt`, early-stopped, best val_bce 0.3985 →
  `phase4/models/sem_best_2000.pt`.
- **Eval (in-sample, coarse has no held-out test):**
  `AUROC=0.877  AP=0.706  IoU=0.396@0.5  best-F1=0.70 @ thresh 0.434
   Prec=0.75 Rec=0.46 @0.5`

### How to read it (IMPORTANT)
- AUROC 0.877 (up from old in-sample ~0.72) and the calibration **flipped from
  over-prediction to under-prediction** (use threshold ≈ **0.43**, not 0.5).
- **BUT the numbers are an upper bound twice over:** (1) in-sample, (2) circular
  — trained on 2020 pseudo-labels and scored against those same labels. So 0.877
  means "the 2000 model learned to reproduce the 2020 model on 2000 imagery,"
  NOT "the 2000 mask is accurate." Not honest accuracy.
- Parking-lot QA (`inspect_anchor_labels.py --site Negative_Parking`): labels are
  clean — 0.011% canopy, mean prob 0.04. The 2020 model cleanly separates
  pavement from canopy, so the label source isn't garbage.

### New diagnostic script
`inspect_anchor_labels.py` — read-only QA of the 2020 anchor labels for one site
(RGB / prob / label-overlay PNG → `phase4/qa/`). `--site`, `--prob-hi/lo`.
