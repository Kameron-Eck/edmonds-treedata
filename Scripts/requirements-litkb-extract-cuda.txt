# WHAT THIS IS AND IS NOT. This is a MEASUREMENT environment, not the default. Nothing in

# this one deliberately, with LITKB_EXTRACT_PYTHON or the bench's --python, and pass
# --device cuda; otherwise it sits there costing disk and nothing else.
#
# WHY IT EXISTS. The independent referee established that a compatible CUDA wheel exists
# (LITKB_DOCLING_LOCAL_REFEREE_2026-09-15.md §6): torchvision 0.29.0 requires torch==2.14.0
# EXACTLY, and cu130 is the only channel carrying a 2.14.0 cp312 win_amd64 pair; the card is
# a Quadro T2000, sm_75 (Turing), which CUDA 13.x still supports, with ~3.1 GB of its 4 GB
# free. The referee measured none of it. Kam's decision A asked for the trial; the numbers
# are in Reports/LITKB_DOCLING_LOCAL_2026-09-15.md, "Decision A implemented".
#
# HOW IT WAS BUILT — and this is the reason the comparison means anything. It is the CPU
# freeze with EXACTLY TWO LINES CHANGED, torch and torchvision. Diffed 2026-09-15:
#
#   < torch==2.14.0            > torch==2.14.0+cu130
#   < torchvision==0.29.0      > torchvision==0.29.0+cu130
#
# Every other package, down to the patch version, is identical to the venv the CPU numbers
# were measured in. So a CPU/GPU difference is attributable to the wheel and to nothing else.
#
#   py -3.12 -m venv D:\edmonds-pipeline\venv-docling-cuda
#   D:\edmonds-pipeline\venv-docling-cuda\Scripts\python.exe -m pip install ^
#       torch==2.14.0+cu130 torchvision==0.29.0+cu130 ^
#       --index-url https://download.pytorch.org/whl/cu130
#   D:\edmonds-pipeline\venv-docling-cuda\Scripts\python.exe -m pip install ^
#       -r Scripts\requirements-litkb-extract-cuda.txt
#
# THE TORCH LINES NEED THE PYTORCH INDEX. `+cu130` is a local version label and PyPI does
# not serve it, so the two lines below are unsatisfiable from PyPI alone — install them
# first from the index URL above, then this file for the rest. That ugliness is deliberate:
# a file that silently fell back to the CPU wheel would reproduce the wrong environment and
# report GPU numbers measured on a CPU.
#
